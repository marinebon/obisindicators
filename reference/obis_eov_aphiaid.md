# AphiaID seeds for one or more EOVs

AphiaID seeds for one or more EOVs

## Usage

``` r
obis_eov_aphiaid(eov)
```

## Arguments

- eov:

  EOV name(s); see
  [`obis_eov_seeds()`](https://marinebon.org/obisindicators/reference/obis_eov_seeds.md).

## Value

integer vector of seed AphiaIDs (union across the named EOVs).
